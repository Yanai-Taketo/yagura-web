プライバシーポリシー — 広告と外部送信について

当サイト（yagura.ta-yan.ai）における、広告の配信、Cookie、外部への情報送信の取り扱いをまとめたものです。ログ集約の道具を配る場所として、こちらの側の情報の扱いも明らかにしておきます。

当サイトについて

当サイトは、OSS の syslog 集約サーバ「Yagura（やぐら）」の紹介と解説を目的とした静的なウェブサイトです。会員登録の仕組みはなく、氏名・住所・電話番号などの個人情報を入力していただく画面はありません。お問い合わせは電子メールでのみ受け付けています。

サイトの配信には GitHub Pages（GitHub, Inc.）を利用しています。同社のサーバには、配信に伴う技術的な記録（アクセス元の IP アドレス等）が残ります。

広告の配信について

当サイトの読みもの（ブログ）の頁では、運営費および開発の継続のため、第三者配信の広告サービス「Google AdSense」を利用することがあります。広告の枠には 「広告」 の札を付けて、記事本文と見分けが付くようにしています。

Google を含む第三者配信事業者は、Cookie を使用して、利用者が当サイトや他のサイトに過去に訪れた際の情報に基づいて広告を配信することがあります。これはパーソナライズ広告と呼ばれるもので、利用者ご自身で Google の広告設定から無効にできます。また aboutads.info では、パーソナライズ広告に使用される第三者配信事業者の Cookie を一括して無効にする方法が案内されています。

Google が広告 Cookie を使用する方法の詳細は、「広告 - ポリシーと規約 - Google」をご確認ください。

心　得

当サイトでは、画面に貼り付く帯広告（アンカー広告）や、画面全体を覆う広告（インタースティシャル）は使用しません。広告は本文の区切りにのみ置き、一つの頁に出す数は最大三つまでとしています。また、広告の読み込みはその枠が画面に近づくまで行わないため、読まなかった頁の広告のために通信が発生することはありません。

電気通信事業法（第 27 条の 12）に基づき、当サイトの閲覧に伴って利用者の端末から外部へ送信される情報を、以下のとおり公表します。

いずれも、氏名・電話番号・メールアドレスなど、利用者を直接特定する情報を当サイトから送信することはありません。

アクセス解析について

当サイトでは、Google アナリティクスをはじめとするアクセス解析ツールを使用していません。閲覧の記録は、配信元である GitHub Pages に残る技術的な記録を除き、当方では取得していません。

広告の表示を止めたいとき

広告を煩わしく感じられる場合は、下の「止める」を押してください。この browser にその設定を記憶し、以後は広告を読み込まなくなります（外部への通信も行いません）。代わりに Yagura 自身の案内が表示されます。

広告の表示を止める 広告の表示を戻す

この設定は、お使いの browser にのみ保存されます（localStorage）。

なお、browser 側の設定で通信量の節約（Save-Data）を有効にされている場合も、当サイトは外部の広告を読み込みません。

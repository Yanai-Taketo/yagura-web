読みもの — syslog とログ集約の帖

Windows ネイティブの OSS syslog 集約サーバ「Yagura（やぐら）」の版元がしるす、syslog サーバの基礎と Windows での実践の読みもの。仕組みの理解から、構築、集約、選定まで。

  • 基礎 syslog サーバとは？ 仕組み・ポート・RFC を基礎から解説 ネットワーク機器やサーバのログを一か所に集める syslog の仕組みを、プロトコルの成り立ち、UDP/TCP 514 と TLS 6514 の使い分け、RFC 3164 と RFC 5424 の違いまで、初めての方向けに整理します。 2026年7月26日
  • 基礎 syslog は UDP と TCP のどちらを使うべき？ TLS（6514）は必要？ どちらでも「動く」だけに迷いやすい転送方式の選択。UDP と TCP の性質の違い、使い分けの指針、そして syslog over TLS が必要になる場面・ならない場面を実務目線で整理します。 2026年7月26日
  • 疑問 Windows 標準機能で syslog は受信できる？ — 答えと現実的な選択肢 検索で辿り着く定番の疑問に、まず結論から。イベントログや Windows イベント転送（WEF）との違いを整理し、Windows 環境で syslog を受けるための現実的な四つの道を比較します。 2026年7月26日
  • 構築 Windows で無料の syslog サーバを構築する方法【OSS・設定ファイル不要】 Linux を用意せず、ライセンス費用も掛けずに、Windows Server 上へ syslog サーバを立てる手順。MSI の実行から機器の送信先設定、ブラウザでの閲覧まで、Yagura を使った最短の道筋を示します。 2026年7月26日
  • 設定 ネットワーク機器の syslog 送信設定まとめ — FW・スイッチ・AP・UPS 機種ごとに画面は違っても、設定する内容は三要素に集約されます。CLI 機器と GUI 機器それぞれの勘所、debug レベルの落とし穴、NTP の重要性、設定後の確認方法までをまとめます。 2026年7月26日
  • 集約 Windows イベントログを syslog サーバへ集約する方法（Fluent Bit 活用） ネットワーク機器の syslog と Windows サーバのイベントログを、同じ画面で横断検索する。Fluent Bit を使った転送の考え方と、Yagura のフォワーダキットによる省力化の手順を解説します。 2026年7月26日
  • 保守 syslog が届かない・受信できないときの確認手順【チェックリスト】 UDP の syslog は失敗してもエラーを返しません。送信側 → 経路 → 受信側 → 形式の順に潰していく切り分け手順を、チェックリスト形式でまとめます。514 番の競合や解析失敗の見つけ方も。 2026年7月26日
  • 設計 syslog サーバのディスク容量はどれくらい必要？ 見積もりの計算式 EPS × 平均サイズ × 保持日数 —— 見積もりの式は一つに決まっています。規模別の試算例、データベースのオーバーヘッド、ログが急増する要因と、あふれさせないための設計までを解説します。 2026年7月26日
  • 運用 ログの保存期間はどのくらい必要？ 目安と設計の考え方 一律の法定保存期間はあるのか。PCI DSS など参考になる基準と目的別の目安を整理し、決めた期間を人手に頼らず守るための、保持期間の自動削除による設計までをまとめます。 2026年7月26日
  • 選定 syslog サーバの選び方 — 商用製品・Linux 系 OSS・Windows ネイティブの比較 商用の syslog 製品、rsyslog や syslog-ng などの Linux 系 OSS、そして Windows ネイティブという三つの道を、導入コスト・必要スキル・運用負荷の観点で比べ、規模と体制に合う選び方を考えます。 2026年7月26日
